# 회차 쓰기

집필 작업대에서 다음 회차를 쓰고, 진행 상황을 지켜보고, 마지막 회차를 다시 생성하거나 되돌립니다.

## 작업실 둘러보기

작품을 열면 위쪽에 제목·진행률·**AI 사용량**이 보이고, 오른쪽에 **📤 내보내기**, **📖 읽기 모드**, **← 목록** 버튼이 있습니다. 왼쪽 사이드바로 작품의 각 화면을 오갑니다.

| 사이드바 | 무엇을 하는 곳 |
|---|---|
| **개요** | 작품의 홈. 표지·로그라인, "이어 쓰기" 버튼, 진행·검토 필요 회차·미회수 약속·AI 사용량 요약 카드 |
| **집필 작업대** | 회차를 읽고, 다음 회차를 쓰는 핵심 화면 |
| **설정집** | 설정집·공식 설정·작품 노트·문체(탭으로 전환) |
| **인물 관계** | 인물·세력을 점으로, 관계를 선으로 보는 관계도 |
| **세계관 만들기** | 대화하며 인물·설정을 더 넓히는 화면 |
| **연재 관리** | 연재 현황·이야기 구조(탭으로 전환) |
| **✨ 스킬** | 이 작품에 적용할 문체·전개 프리셋 관리 |

**개요** 화면의 요약 카드는 클릭할 수 있습니다 — "검토 필요 회차"를 누르면 해당 회차로 바로 이동하고, "미회수 약속"은 연재 관리로 이어집니다.

## 집필 작업대 살펴보기

집필 작업대는 좌우 두 칸입니다.

- **왼쪽(회차 읽기)**: 위쪽에 회차 번호 칸(예: `1화` `2화` …)이 있고, 그 아래에 고른 회차의 본문이 펼쳐집니다. 회차가 24개를 넘으면 `◀ ▶`로 묶음을 넘깁니다.
- **오른쪽(회차 집필)**: 다음 회차를 쓰는 조작판입니다.

## 다음 회차 쓰기

오른쪽 칸에서 필요하면 **작가 지시**를 적고(비워도 됩니다), **다음 회차 쓰기**를 누릅니다.

집필이 시작되면 **진행 표시**가 실시간으로 흐릅니다 — "회차 구상 → 본문 집필 → 일관성 검사 → 문장 다듬기 → 마무리" 같은 단계가 한 줄씩 올라오고, 화면 위쪽에는 "N화 집필 중 · 경과시간"이 계속 보입니다. 한 회차는 보통 1~3분 걸립니다.

완료되면 새 회차가 왼쪽에 나타나고, 본문 위에 **완성** 또는 **검토 필요** 배지가 붙습니다. **검토 필요** 배지가 붙은 회차에는 무엇이 충돌했고 어떻게 풀 수 있는지 안내가 함께 뜹니다. 설정을 고친 뒤 다시 생성하면 반영됩니다.

💡 팁 — 연결이 끊기거나 새로고침해도 집필은 서버에서 계속되며, 다시 들어오면 진행 중인 회차에 자동으로 다시 연결됩니다. 화면 오른쪽 위 연결 표시는 정상일 때 숨겨지고, 끊겼을 때만 안내가 뜹니다.

## 작가 지시 활용하기

집필 칸의 **작가 지시**에 이번 회차에서 지킬 제약을 자연어로 적으면 다음 회차부터 반영됩니다 — 예: "강도현은 이미 죽었다(직접 등장 금지)", "주인공의 트라우마를 부각".

**계속 적용**을 체크하면 그 지시를 이어지는 회차에도 유지합니다(아크 내내 지킬 제약에 유용). 체크하지 않으면 그 회차에만 적용됩니다.

## 마지막 회차 다시 생성 · 되돌리기

마지막 회차에는 본문 제목 옆에 추가 버튼이 나타납니다.

- **🔄 이 회차 다시 생성** — 현재 설정·지시 그대로 마지막 회차를 새로 씁니다. 지금 내용은 자동 백업됩니다.
- **🔧 점검 반영해 다시 생성** — 연속성·세계 규칙·전개 점검 항목이 있을 때, 고칠 항목을 골라 그 사실을 지켜 다시 씁니다.
- **↩ 재생성 되돌리기** — 다시 생성 직전의 회차로 복구합니다.
