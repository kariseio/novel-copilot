# 회차 다듬기

이미 쓴 회차를 다듬는 세 가지 길을 안내합니다 — 문장만 손보는 퇴고, 회차를 통째로 새로 뽑는 재생성, 문체를 근본부터 다시 실현하는 재실현. 모두 되돌릴 수 있습니다.

## 퇴고 (문장만 다듬기)

회차 본문 제목 옆 **퇴고** 버튼을 누르면 다듬기 창이 열립니다. 설정·사건·이름·수치는 바뀌지 않고 문장 표현만 손봅니다.

1. **작가 지시**를 적습니다 — 예: "이 대목 더 간결하게", "대사 톤 차갑게". 예시 칩(더 간결하게 / 대사 톤 차갑게 / 묘사 줄이기 등)을 눌러 채워도 됩니다.
2. 일부만 고치고 싶으면 **다듬을 구간**에 본문에서 그 부분을 그대로 붙여넣습니다(비우면 전체). 필요하면 "행 정렬 다듬기"(문단 조판 정리), "시제 교정"을 함께 켤 수 있습니다.
3. **다듬기 →** 를 누르면 원문과 다듬은 글의 차이(diff)가 표시됩니다(삭제·추가를 색으로 구분, "나란히 보기"로도 볼 수 있음).
4. 자동 점검이 "설정 충돌은 발견되지 않았어요"라고 확인하면 **채택** 버튼이 활성화됩니다. 채택하면 본문에 반영됩니다. 이름·수치가 바뀌었거나 분량이 크게 달라졌으면 채택이 막히고 이유가 표시됩니다.
5. 마음에 안 들면 회차 본문 옆 **마지막 퇴고 되돌리기**로 다듬기 전으로 돌립니다.

ℹ️ 참고 — 퇴고로 본문이 바뀌면 인물 노트·복선 정리 등 파생 정보가 잠시 어긋날 수 있다는 안내가 뜹니다. 그 회차를 다시 생성하면 최신 본문 기준으로 갱신됩니다.

## 재생성 (회차 통째로 다시)

퇴고가 문장 손질이라면, 재생성은 회차를 통째로 새로 뽑는 방식입니다. 마지막 회차에서 **🔄 이 회차 다시 생성**을 누르면 됩니다. 자세한 조작은 [회차 쓰기](write-chapters.md)에서 다룹니다.

## 재실현 (문체를 근본부터 다시)

**재실현**은 회차를 사실 뼈대와 대사만 남기고 웹소설 문체로 다시 써내는 기능입니다. 문장 끝맺음이 단조롭게 이어질 때의 근본 처방입니다.

![재실현 흐름: 원문에서 사실 뼈대·대사 추출 → 후보 3편 병렬 → 문체 계측으로 최적 1편 선택 → 사실 보존 검사 → 가상 독자 정독. 통과하면 채택(되돌리기 가능), 원문이 더 잘 읽히면 채택 거부·원문 유지(원문 보호 원칙)](/img/docs/rerender-noharm.svg)
*원문(사실 뼈대+대사) → 후보 3편 비교 선택 → 사실 보존 검사 → 가상 독자 정독(vs 원문). 통과하면 채택(되돌리기 가능), 원문이 더 잘 읽히면 채택을 거부하고 원문을 유지합니다(원문 보호 원칙).*

작동 방식은 이렇습니다.

1. 회차에서 사실 뼈대(사건 요약)와 대사·수치·고유명사를 추출합니다. 원문 문장 자체는 넘기지 않습니다.
2. 같은 재료로 후보 3편을 만든 뒤, 문체 계측이 사람 글 범위에 가장 가까운 한 편을 고릅니다(후보 3편 비교 선택).
3. 사실 보존 검사를 통과한 뒤, 가상 독자가 원문과 다시 실현한 글을 정독해 비교합니다.
4. 원문이 더 잘 읽히면 다시 실현한 글을 스스로 채택하지 않고 원문을 유지합니다(원문 보호 원칙).

실측에서 대표 지표('-었다' 지배율)를 0.77에서 0.36~0.41(사람 글 범위)로 옮기면서, 가상 독자 정독에서 원문과 대등하거나 더 나은 평가를 받았습니다.

ℹ️ 참고 — 재실현은 현재 API로만 제공되며 **웹 버튼은 준비 중**입니다.
