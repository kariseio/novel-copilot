# 검증 리포트 읽기

회차 본문 위쪽 **회차 검증** 패널을 읽는 법입니다. 여기 나오는 값들은 모두 참고 자료이며, 어떤 값도 회차를 막거나 자동으로 고치지 않습니다.

## 회차 검증 리포트란 무엇인가요?

매 회차가 계획·집필·교정을 거친 결과를 한 리포트로 모은 것입니다. 확정 설정 충돌·문체 계측·가상 독자 반응 등 여러 축을 회차마다 원자료로 보여줍니다. 판정 라벨을 붙이지 않으며, 돌지 않은 검사는 "미실행"으로 정직하게 표기합니다("0"으로 위장하지 않습니다).

이 숫자들은 "사람이 쓴 것처럼 읽히는가"를 가늠하는 참고선입니다. 판단은 작가가 합니다.

## 각 지표 읽는 법

- **확정 설정 충돌** — 작품에서 사실로 확정한 설정과 어긋난 부분입니다. "하드 0"(치명적 충돌 없음)이 발행의 기본선입니다.
- **문체 신호** — 쉼표 밀도, 문장 길이 변동, 어휘 다양성, 종결형 다양성 등입니다. 문장의 리듬과 반복 정도를 보는 숫자입니다.
- **문말 종결 계측** — 문장 끝맺음이 한 가지로만 반복되는지 보는 문체 계측입니다. 옆에 **사람 글 범위(참고선)** 가 함께 표시됩니다(예: '~다(과거)'가 연속으로 이어지는 정도가 대략 3 안팎이면 사람 글의 흔한 범위).
- **도입부 반복도** — 앞 회차와 이번 회차의 도입부가 얼마나 비슷한지 봅니다(1화처럼 앞 회차가 없으면 "미실행").
- **분량** — 글자 수와 권장 분량 대비 비율입니다(코드가 판정하는 값이 아닙니다).
- **가상 독자 반응** — 가상 독자의 잔존 추정과 이탈 신호입니다. 실제 독자가 아니라 AI 시뮬레이션입니다.
- **발행 게이트** — 발행 게이트를 켰을 때만 결과가 채워집니다(기본은 꺼짐).

ℹ️ 참고 — 어떤 값이 "미실행"이면 그 점검이 이 회차에서 돌지 않았다는 정직한 표시일 뿐입니다. 값이 사람 글 범위를 벗어나더라도 그것만으로 불합격이 되지 않습니다.

## 각 축은 어디서 나오나요?

리포트의 축들은 회차가 만들어지는 과정에서 자동으로 집계됩니다.

- **확정 설정 충돌**은 완성 본문을 확정 설정과 대조하는 사실 교정 단계에서 나옵니다.
- **문체 신호**와 **문말 종결 계측**은 형태소 단위 문체 계측에서 나오며, 사람 글 범위를 참고선으로 병기합니다.
- **가상 독자 반응**은 초비판 독자 시뮬레이션이 회차를 정독해 남긴 예상 잔존율·이탈 신호입니다.
- **발행 게이트** 판정은 게이트를 켰을 때만 채워집니다.

각 단계가 어떻게 도는지는 [작동 방식](how-it-works.md)에서 자세히 다룹니다.

## 검토가 필요할 때

**검토 필요** 배지가 붙은 회차에는 무엇이 충돌했고 어떻게 풀 수 있는지 안내가 함께 뜹니다. 확정 설정을 고친 뒤 다시 생성하면 최신 설정 기준으로 반영됩니다.
