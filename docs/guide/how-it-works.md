# 작동 방식 — 한 회차가 만들어지기까지

"AI가 소설을 써 준다"는 서비스는 많지만, NovelCopilot의 차이는 쓰고 난 다음에 있습니다. 매 회차가 계획→집필→검증→수리의 과정을 통과하고, 그 기록이 전부 남습니다. 이 문서는 그 과정을 작가 눈높이에서 소개합니다.

## 작품이 만들어질 때 — 한 번

세계관 빚기(대화)를 확정하는 순간, 연재의 뼈대가 한 번에 준비됩니다.

![작품 생성 흐름: 세계관 빚기 대화에서 세계관·인물, 이야기 구조(엔딩에서 역산), 설정집, 서술자 목소리가 한 번에 준비되어 연재가 시작된다](/img/docs/worldgen.svg)
*대화(세계관 빚기) → 세계관·인물 / 이야기 구조(엔딩에서 역산) / 설정집 / 서술자 목소리 → 연재 시작.*

| 준비물 | 내용 |
|---|---|
| 세계관·인물 | 전제·세계 규칙·인물 시트(욕망·관계·비밀) |
| 이야기 구조 | 엔딩을 먼저 확정하고 거기서 역산한 아크/에피소드 구조 — 매 회차가 "결말 있는 질문" 위에서 쓰이게 |
| 설정집 | 장르 산문으로 정리된 세계 문서 |
| 서술자 목소리 | 주인공 인격에서 파생한 서술 음성 — 작품마다 다른 결의 문장이 나오는 이유 |

## 매 회차가 만들어질 때 — "다음 회차 쓰기" 버튼 뒤에서

![회차 생성 8단계: 회차 계획 → 재료 조립 → 집필 → 사실 교정 → 문체 다듬기 → 파생물 → 검증 리포트 → 발행 게이트](/img/docs/pipeline-chapter.svg)
*① 회차 계획 ② 재료 조립 ③ 집필(집필 AI) ④ 사실 교정 ⑤ 문체 다듬기 ⑥ 파생물 ⑦ 검증 리포트 ⑧ 발행 게이트(선택) — 계획→집필→검증→수리.*

### ① 회차 계획
이야기 구조에서 이번 회차의 회차 계획(일어날 사건들)을 뽑습니다. 독자에게 지불되는 보상이 어디서 터질지도 이 단계에서 배치됩니다.

### ② 재료 조립
확정 설정(인물의 현재 상태·관계·세계 규칙)을 집필 프롬프트에 사실로 박아 넣고, 지난 이야기 요약과 회수할 복선을 검색해 곁들입니다. 서술자 목소리도 이때 들어갑니다.

### ③ 집필
본문을 씁니다(집필 AI). 분량은 글자 수를 지시해서 채우지 않습니다 — 계획된 사건이 남아 있을 때만 이어 쓰는 방식이라, 분량을 위한 물타기가 구조적으로 없습니다.

### ④ 사실 교정
완성 본문을 확정 설정과 대조해 충돌(죽은 인물 등장, 상태 모순 등)을 잡고 자동 교정을 시도합니다. 끝내 남으면 검토 필요 상태로 정직하게 표시됩니다.

### ⑤ 문체 다듬기
단조로운 리듬 구간을 그 부분만 수리하고, AI 티 다듬기가 'AI 티' 문장(자기 해설·감정 명명 등)을 그 부분만 수술합니다 — 사실이 바뀌면 수술 자체가 채택되지 않는 가드가 걸려 있습니다.

### ⑥ 파생물 갱신
요약·작품 노트·약속 원장 정산·가상 독자 반응(이탈 신호·예상 잔존율)이 함께 기록됩니다.

### ⑦ 검증 리포트
위 전 과정의 결과가 회차마다 리포트로 남습니다 — 확정 설정 충돌 수, 문체 계측(사람 글 범위와 비교), 도입부 반복도, 가상 독자 반응, 게이트 판정. 돌지 않은 검사는 "미실행"으로 표기합니다. 숫자를 좋게 꾸미지 않는 것이 이 서비스의 원칙입니다. 각 지표의 뜻은 [검증 리포트 읽기](read-verification.md)를 참고하세요.

### ⑧ 발행 게이트 (선택)
켜 두면 발행 직전에 초비판 독자가 정독합니다 — 돈과 시간을 아까워하는 독자 시뮬레이션이 이탈 신호를 찾고, 실재하면 그 부분을 수정한 뒤 재심사합니다. 집필과 심사는 서로 다른 회사의 AI를 씁니다(자기 채점 금지).

## 발행 후에도 — 전부 되돌릴 수 있는 다듬기

- **퇴고** — 지시문("초반 대화를 날카롭게")대로 문장만 수정. 사실 보존 검사 + 변경 내역 확인 + 되돌리기.
- **재실현** — 문체를 근본부터 다시. 같은 사건·같은 대사를 유지한 채 회차를 웹소설 문체로 재집필하고, 후보 여러 편 중 문체 계측이 가장 좋은 편을 고른 뒤, 원문보다 못 읽히면 스스로 채택을 거부합니다(원문 보호 원칙). 실측으로 'AI 티' 대표 지표를 사람 글 범위까지 옮긴, 이 서비스의 간판 기능입니다. 생성 파이프라인에도 기본 내장되어, 매 회차 발행 직후 자동 실행됩니다(원문 보호 원칙 그대로 — 못하면 채택하지 않습니다). 설정에서 끌 수 있습니다.

  ![재실현 흐름: 원문에서 사실 뼈대·대사 추출 → 후보 3편 병렬 → 문체 계측으로 최적 1편 선택 → 사실 보존 검사 → 가상 독자 정독. 통과하면 채택(되돌리기 가능), 원문이 더 잘 읽히면 채택 거부·원문 유지(원문 보호 원칙)](/img/docs/rerender-noharm.svg)
  *원문(사실 뼈대+대사) → 후보 3편 비교 선택 → 사실 보존 검사 → 가상 독자 정독(vs 원문). 통과하면 채택(되돌리기 가능), 원문이 더 잘 읽히면 채택을 거부하고 원문을 유지합니다(원문 보호 원칙).*
- **재생성/복원** — 마지막 회차를 다시 쓰거나 이전 판으로 되돌리기.

## 품질을 지키는 네 가지 원칙

![품질 구조: 생성(집필 AI) → 본문 → 심사(교차 심사 AI, 자기 채점 금지). 사실 가드(확정 설정)와 계측(참고선)이 곁에서 받치고, 최종 결정은 작가(무강제)](/img/docs/quality-loop.svg)
*집필(집필 AI) → 본문 → 교차 심사(다른 회사 AI, 자기 채점 금지). 사실 가드(확정 설정)와 계측(참고선)이 곁에서 받치고, 최종 결정은 작가에게 있습니다.*

1. **정독이 1차** — 합격/불합격은 "읽히는가"로 판단하고, 수치는 참고선으로만 씁니다.
2. **교차 심사** — 쓰는 AI와 평가하는 AI를 다른 회사 것으로 분리합니다.
3. **사실은 가드** — 어떤 자동 편집도 사실을 바꾸면 채택되지 않습니다.
4. **작가 주권** — 시스템은 측정하고 제안할 뿐, 자동으로 발행을 막거나 다시 쓰지 않습니다. 모든 개입은 켜고 끌 수 있고, 되돌릴 수 있습니다.
