# 설정 레퍼런스

작가가 조정할 만한 설정을 한자리에 모았습니다. 대부분 그대로 두어도 잘 동작하므로, 특정 동작을 켜거나 끄고 싶을 때만 참고하세요.

설정은 환경변수로 주입합니다(오른쪽 병기 열의 환경변수 키를 `app/.env`에 넣으면 됩니다).

## 품질과 검증

| 설정 | 기본값 | 설명 | 환경변수 키 |
|---|---|---|---|
| 발행 게이트 | 꺼짐 | 발행 직전 가상 독자가 정독해 이탈 지점을 그 부분만 수리합니다. 켜면 품질 점검이 촘촘해지는 대신 시간과 AI 사용량이 늘어납니다. 잘 모르겠으면 꺼둔 채 시작하세요. | `NOVEL_PRODUCT_GATE` |
| 가상 독자 반응 | 켜짐 | 매 회차 가상 독자의 이탈 신호·예상 잔존율을 기록합니다(참고선). AI 사용량을 아끼려면 끕니다. | `NOVEL_READER_DESK` |
| 사실 모순 점검 | 켜짐 | 본문의 자유형 사실 모순을 지난 회차와 대조해 참고로 표시합니다(발행을 막지 않음). | `NOVEL_CLAIM_AUDIT` |
| 회차 내 연속성 교정 | 켜짐 | 한 회차 안에서 수치·소지품 같은 연속성 오류를 다듬습니다. | `NOVEL_CONTINUITY_POLISH` |

## 문체와 조판

| 설정 | 기본값 | 설명 | 환경변수 키 |
|---|---|---|---|
| AI 티 다듬기 | 켜짐 | 회차를 마무리하며 'AI 티' 문장(자기 해설·감정 명명 등)을 그 부분만 다듬습니다. 사실이 바뀌면 다듬기가 채택되지 않습니다. | `NOVEL_HUMANIZE` |
| 서술자 목소리 | 켜짐 | 1인칭 작품에서 주인공 인격을 바탕으로 서술자 목소리를 자동으로 만듭니다. 작품마다 다른 결의 문장이 나오는 이유입니다. | `NOVEL_NARRATOR_VOICE` |
| 문단 조판 정리 | 켜짐 | 발행 직전 문단을 읽기 좋게 정리합니다(내용은 바뀌지 않습니다). | `NOVEL_PARAGRAPH_REFLOW` |
| 전개 압력 안내 | 켜짐 | 회차 집필에 이야기를 전진시키라는 안내를 더해 물타기를 줄입니다. | `NOVEL_CRAFT_PROGRESS` |
| 생성 중 문체 재실현 | 꺼짐 | 켜면 회차를 발행한 직후 문체 재실현을 자동으로 한 번 돌립니다(원문 보호 원칙 그대로 — 원문보다 못 읽히면 채택하지 않습니다). 기본은 꺼짐 — 재실현은 수동 발동(퇴고 화면/API)으로만 씁니다. | `NOVEL_RERENDER_IN_PIPELINE` |
| 재실현 후보 수 | 3 | 재실현할 때 만들 후보 편수입니다(많을수록 비용 증가). | `NOVEL_RERENDER_BON_N` |
| 재실현 정독 게이트 | 켜짐 | 재실현한 글이 원문보다 못 읽히면 채택하지 않고 원문을 유지합니다(원문 보호 원칙). | `NOVEL_RERENDER_READ_GATE` |

## 회차 계획

| 설정 | 기본값 | 설명 | 환경변수 키 |
|---|---|---|---|
| 적시 사건 메뉴 | 켜짐 | 에피소드마다 신선한 사건 후보를 뽑아 회차 계획이 반복되지 않게 돕습니다. | `NOVEL_EVENT_MENU` |

## 모델과 API 키

집필·심사에 쓰는 AI는 아래 값으로 정해집니다. 특별한 이유가 없으면 기본값을 권장합니다.

| 설정 | 기본값 | 설명 | 환경변수 키 |
|---|---|---|---|
| 집필 모델 | `claude-opus-4-6` | 본문을 쓰는 집필 AI(Claude)입니다. | `NOVEL_GEN_MODEL` |
| 표지 이미지 모델 | `gpt-image-2` | 표지 이미지를 만드는 모델입니다. | `NOVEL_IMAGE_MODEL` |
| 데이터 폴더 | 비움(기본 위치) | 작품 데이터를 저장할 폴더입니다. 비우면 `app/data`를 씁니다. | `NOVEL_DATA_DIR` |

API 키(`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`)를 넣는 방법은 [설치와 실행](setup.md)에서 다룹니다.
