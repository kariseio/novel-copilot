# 작품 만들기

새 작품을 만드는 두 가지 길을 안내합니다. 확정하면 세계관·인물·설정집·이야기 구조·서술자 목소리가 한 번에 준비됩니다.

![작품 생성 흐름: 세계관 빚기 대화에서 세계관·인물, 이야기 구조(엔딩에서 역산), 설정집, 서술자 목소리가 한 번에 준비되어 연재가 시작된다](/img/docs/worldgen.svg)
*대화(세계관 빚기) → 세계관·인물 / 이야기 구조(엔딩에서 역산) / 설정집 / 서술자 목소리 → 연재 시작.*

## 첫 화면 살펴보기

첫 화면은 크게 두 칸입니다.

- **왼쪽 — 내 작품**: 지금까지 만든 작품이 책장처럼 늘어섭니다. 각 카드에는 제목·장르·진행률(예: `12/200화`)이 보이고, 카드를 누르면 바로 집필 작업대로 이어집니다(가장 최근에 연 작품은 위쪽에 **이어서 쓰기**로 강조됩니다). 카드의 **삭제** 버튼으로 작품을 지울 수 있습니다(되돌릴 수 없으니 주의).
- **오른쪽 — 새 작품 시작**: 만들고 싶은 이야기를 한 문장으로 적는 칸입니다. 예시 문구를 눌러 채워 넣어도 됩니다.

## 대화로 세계관 빚기 (권장)

오른쪽 칸에 한 줄을 적고 **AI와 이야기 나누기 →** 를 누르면 **세계관 빚기** 화면으로 들어갑니다. 화면은 좌우로 나뉩니다.

- **왼쪽(대화)**: AI가 질문을 던지고, 작가가 답하거나 설정을 덧붙입니다. 길게 쓸 필요 없이 키워드만 던져도 AI가 살을 붙입니다. 아래 추천 질문 버튼을 눌러 바로 답할 수도 있습니다(`Ctrl`/`⌘` + `Enter`로 전송).
- **오른쪽(세계관 브리프)**: 대화 내용이 로그라인·전제·배경·인물·세계 규칙·핵심 갈등으로 차곡차곡 정리됩니다. 위쪽 **완성도** 막대가 채워질수록 이야기가 무르익고 있다는 뜻입니다.
  - **장르·분위기·목표 회차**는 직접 입력하거나 추천 칩을 눌러 정합니다. 여기서 직접 정한 값은 AI 제안보다 우선합니다.
  - **키워드·트로프**는 장르에 맞춰 추천되며, 원하는 것을 눌러 고르거나 직접 입력합니다(최대 6개).

준비가 되면 **세계 생성 →** 을 누릅니다. 로그라인이나 인물이 아직 비어 있으면 "AI가 알아서 채워서 진행할까요?"라고 한 번 확인합니다. 확정하면 세계관·인물·설정집·이야기 구조(단락·결말)·서술자 목소리까지 자동으로 준비되고(1~2분, 진행 상황이 실시간 표시), 완료되면 작업실로 이동합니다.

## 한 줄 발상으로 바로 시작

대화를 오래 하고 싶지 않다면, 오른쪽에서 장르·분위기·키워드만 칩으로 골라 두고 곧바로 **세계 생성 →** 을 눌러도 됩니다. 대화 없이도 그때까지 고른 설정을 반영해 세계를 만듭니다.

잘 모르겠으면 대화로 세계관을 빚는 길로 시작하세요 — AI가 질문으로 이끌어 줍니다.

## 좋은 브리프 쓰는 법

💡 팁 — "장르 + 주인공의 처지 + 특별한 한 가지" 한 줄이면 충분합니다. 예: *"기억을 사고파는 도시에서, 자기 기억이 위조된 걸 깨달은 기억 거래상 이야기."* 로그라인과 주인공만 있어도 세계 생성을 시작할 수 있고, 나머지는 대화에서 자라납니다.

## 세계 생성 스킬 적용하기

작품을 만드는 단계에도 문체나 전개의 결을 담은 스킬을 적용할 수 있습니다. 세계 생성 스킬은 **새 작품 만들기** 화면에서만 고를 수 있으며, 이미 만든 세계에는 다시 적용되지 않습니다. 스킬을 만들고 관리하는 방법은 [작품 설정 관리](manage-assets.md)에서 다룹니다.
