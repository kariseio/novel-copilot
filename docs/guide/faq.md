# FAQ

품질·사용·데이터와 저작권에 대해 자주 묻는 질문을 모았습니다. 실행·서버·오류 관련 문답은 [문제 해결](troubleshooting.md)과 [설치와 실행](setup.md)에 있습니다.

## 품질

**Q. AI가 쓴 티가 나지 않나요?**
문제를 정면으로 다루는 게 이 서비스의 핵심입니다. 모든 회차를 형태소 단위로 계측해(문장 끝맺음의 단조로움, 같은 어미의 연속 등) 실제 인기 웹소설에서 잰 사람 글 범위와 비교해 보여주고, 범위 밖이면 재실현(같은 사건·같은 대사를 웹소설 문체로 다시 실현)으로 근본적으로 바꿀 수 있습니다. 재실현은 실측에서 대표 지표('-었다' 지배율)를 0.77에서 0.36~0.41(사람 글 범위)로 옮기면서, 가상 독자 정독에서 원문과 대등하거나 더 나은 평가를 받았습니다.

**Q. 설정 오류(어제 죽은 인물이 오늘 등장)는 어떻게 막나요?**
작품의 확정 설정(인물 상태·관계·세계 규칙)을 단일 출처로 관리하고, 집필 때 프롬프트에 사실로 박아 넣은 뒤 완성 본문을 다시 검사합니다. 충돌이 있으면 자동 교정을 시도하고, 남으면 검토 필요 상태로 표시합니다. 퇴고·재실현 같은 편집 기능도 사실이 바뀌면 채택 자체가 거부됩니다.

**Q. 재미는 누가 판단하나요?**
초비판 독자 시뮬레이션이 매 회차를 정독하고 이탈 신호·예상 잔존율을 남깁니다. 집필 AI와 심사 AI를 다른 회사 것으로 나눠(교차 심사) 자기 채점을 막습니다. 발행 게이트를 켜면 이탈 신호가 실재할 때 그 부분 수리와 재심사까지 자동으로 돕니다(기본은 꺼짐).

**Q. 계측 수치가 사람 글 범위 밖이면 불합격인가요?**
아닙니다. 모든 수치는 참고선이고 자동 판정·자동 재작성은 하지 않습니다. 1차 기준은 언제나 "읽히는가"이며, 최종 결정은 작가가 합니다. 각 지표의 뜻은 [검증 리포트 읽기](read-verification.md)를 참고하세요.

## 사용

**Q. 한 회차 생성에 얼마나 걸리나요? 비용은?**
검증·다듬기까지 포함해 보통 10~30분이며, 발행 게이트를 켜면 더 걸릴 수 있습니다. 비용은 회차당 대략 15~25만 토큰 수준이며, 넣어 둔 API 키로 과금됩니다. 화면에 단계별 사용량이 기록됩니다.

**Q. 문체를 내 취향으로 바꿀 수 있나요?**
문체 설정과 스킬로 조향할 수 있습니다. 다만 실측 결과, 문체의 큰 결은 지시보다 서술자 설계와 재실현이 훨씬 효과적입니다. 작품을 만들 때 주인공 인격에서 서술자 목소리가 자동으로 파생되며, 이것이 작품 고유의 결을 만듭니다. 자세한 조작은 [작품 설정 관리](manage-assets.md)를 참고하세요.

**Q. 여러 작품을 동시에 연재할 수 있나요?**
네. 작품은 서로 독립이며, 목록에서 자유롭게 오가면 됩니다. 단, 한 작품의 회차 생성이 진행 중일 때 같은 작품에 다른 요청을 보내면 작업이 끝난 뒤 다시 시도하라는 응답이 옵니다.

## 데이터·저작권

**Q. 내 작품 데이터는 어디에 있나요?**
전부 컴퓨터 안의 `app/data/projects` 폴더에 JSON 파일로 있습니다. 외부 저장은 없습니다. 회차 본문·설정·퇴고 이력이 모두 포함되며 내보내기로 한 번에 백업할 수 있습니다. 자세한 위치와 백업은 [내보내기와 백업](export-backup.md)을 참고하세요.

**Q. 생성물의 저작권은요?**
현행 한국 저작권 등록 실무는 "인간의 창작적 기여분"을 요구합니다. 이 서비스는 작가의 개입(브리프 확정·지시·퇴고 변경 내역·채택 이력)을 시점과 함께 기록해 두므로, 기여를 보여주는 원자료가 남습니다. 다만 법적 판정은 별개 사안이며 이 문서는 법률 자문이 아닙니다.

**Q. 다른 작품을 베끼지는 않나요?**
실존 작품 원문을 예시로 주입하는 기능은 정책적으로 금지돼 있습니다(수치 통계만 참조). 생성은 작품 고유의 세계관·인물에서만 출발합니다.
