# 빠른 시작

아이디어 한 줄에서 첫 회차까지 5분 안에 시작합니다. 이 문서는 이미 서버가 켜진 상태를 전제로 합니다. 설치와 실행이 아직이라면 먼저 [설치와 실행](setup.md)을 마치세요.

## 준비물

- 실행 중인 서버 — 브라우저에서 `http://localhost:8000`이 열려야 합니다([설치와 실행](setup.md)).
- 만들고 싶은 이야기 한 줄 — "장르 + 주인공의 처지 + 특별한 한 가지"면 충분합니다.

## 첫 작품 만들기

권장 경로는 대화로 세계관을 빚는 방식입니다.

1. 첫 화면 오른쪽 **새 작품 시작** 칸에 이야기를 한 줄 적습니다. 예: *"야간 물류센터에서 일하는 청년이 남들 눈에 안 보이는 것을 보기 시작하는 현대 판타지."*
2. **AI와 이야기 나누기 →** 를 눌러 **세계관 빚기** 화면으로 들어갑니다.
3. AI가 로그라인·핵심 갈등·주인공을 제안하면 대화로 다듬습니다. 오른쪽 브리프에 정리되며, 장르·분위기·키워드는 작가가 직접 정한 값이 AI 제안보다 우선합니다.
4. **세계 생성 →** 을 누르면 세계관·인물·설정집·이야기 구조·서술자 목소리가 자동으로 준비됩니다(1~2분, 진행 상황이 실시간으로 표시됩니다).

💡 팁 — 좋은 시작점은 "장르 + 주인공의 직업이나 처지 + 특별한 한 가지"입니다. 나머지는 대화에서 자라납니다. 자세한 두 가지 경로는 [작품 만들기](create-work.md)에서 다룹니다.

## 첫 회차 쓰기

집필 작업대에서 **다음 회차 쓰기**를 누르면 다음이 자동으로 진행됩니다.

1. 이번 회차의 회차 계획을 세웁니다.
2. 본문을 집필합니다.
3. 확정 설정과 어긋난 부분을 스스로 교정하고 문체를 다듬습니다.
4. 회차 검증 리포트를 남깁니다 — 확정 설정 충돌 여부, 문체 계측이 사람 글 범위와 비교해 어디쯤인지, 가상 독자 반응까지.

회차 화면에서 본문과 회차 검증 리포트를 확인합니다. 이 숫자들은 참고선이지 합격/불합격 판정이 아니며, 최종 판단은 작가가 합니다.

## 마음에 안 들면

- **퇴고** — 회차 화면에서 지시를 입력하면("초반 대화를 더 날카롭게") 사실은 그대로 두고 문장만 고칩니다. 변경 내역(diff)을 보고 채택하거나 되돌립니다.
- **다시 생성** — 마지막 회차를 다시 쓰게 하고, 이전 판으로 복원할 수 있습니다.
- **설정 바로잡기** — 인물 상태나 관계가 틀렸다면 **공식 설정** 탭에서 직접 고치세요. 이후 회차부터 반영됩니다.
