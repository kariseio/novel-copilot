# 문제 해결

회차 생성·서버·표지에서 자주 겪는 증상을 원인과 해결로 정리했습니다.

## 회차 생성이 실패했어요

**원인** — 집필 도중 일부 단계가 실패할 수 있습니다.
**해결** — 단계별 자동 재시도·복구가 내장돼 있고, 실패해도 이전 상태가 보존됩니다(반쪽 상태가 남지 않습니다). 마지막 회차 다시 생성·되돌리기로 언제든 이전으로 복구할 수 있습니다. 자세한 조작은 [회차 쓰기](write-chapters.md)를 참고하세요.

## "작업 중"이라며 요청이 막혀요

**원인** — 한 작품의 회차 생성이 진행 중일 때 같은 작품에 다른 요청을 보내면, 데이터가 엉키지 않도록 서버가 잠급니다(응답 코드 `423`).
**해결** — 진행 중인 작업이 끝난 뒤 다시 시도하세요. 여러 작품은 서로 독립이므로, 다른 작품은 그동안에도 자유롭게 다룰 수 있습니다.

## 새로고침해도 진행 상황이 안 보여요

**원인** — 집필 중 연결이 끊기거나 브라우저를 닫은 경우입니다.
**해결** — 집필은 서버에서 계속 진행됩니다. 다시 들어오면 진행 중인 회차에 자동으로 다시 연결됩니다. 화면 오른쪽 위 연결 표시는 정상일 때 숨겨지고, 끊겼을 때만 안내가 뜹니다.

## 코드를 업데이트했는데 웹에 반영이 안 돼요

**원인** — 작품 데이터 변경은 새로고침으로 즉시 반영되지만, 프로그램 코드 변경은 서버 재시작이 필요합니다.
**해결** — 서버를 다시 시작하세요. 회차 생성이 진행 중이면 끝난 뒤에 재시작하는 것이 안전합니다. 실행·재시작 방법은 [설치와 실행](setup.md)에서 다룹니다.

## 서버가 자꾸 꺼져요

**원인** — 터미널에서 수동으로 실행하면 세션이 끝날 때 서버도 함께 종료될 수 있습니다.
**해결** — 상시 실행 스크립트를 한 번 등록하면 로그인 시 자동으로 시작됩니다. 방법은 [설치와 실행](setup.md)의 상시 실행 절을 참고하세요.

## 표지 생성이 안 돼요

**원인** — 이미지 생성에 실패했거나, 이미 다른 표지 생성이 진행 중일 수 있습니다.
**해결** — 잠시 후 **다시 생성**을 눌러 다시 시도하세요. 프롬프트를 직접 수정하거나 비워서 설정 기반으로 다시 합성할 수도 있습니다. 표지 생성은 20~40초 걸립니다.

## 어떤 점검이 "미실행"으로 나와요

**원인** — 그 점검이 이 회차에서 돌지 않았다는 정직한 표시입니다(예: 도입부 반복도는 1화처럼 앞 회차가 없으면 미실행, 발행 게이트는 꺼져 있으면 미실행).
**해결** — 오류가 아닙니다. 값이 필요하면 해당 기능을 켜세요. 각 지표의 뜻은 [검증 리포트 읽기](read-verification.md)에서 다룹니다.
