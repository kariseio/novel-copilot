# 설치와 실행

NovelCopilot을 처음 실행하고, 상시 구동·업데이트 반영·데이터 백업까지 준비합니다.

## 준비물

- Python 3.12
- API 키 두 개 — 집필용과 심사·임베딩용. `app/.env` 파일에 넣습니다.

```
ANTHROPIC_API_KEY=...   # 본문 집필 — 집필 AI(Claude)
OPENAI_API_KEY=...      # 심사·임베딩 — 교차 심사 AI(GPT)와 검색용
```

ℹ️ 참고 — 본문 집필은 한 회사의 AI(Claude), 심사·임베딩은 다른 회사의 AI(GPT)를 씁니다. 자기 채점을 막기 위해 집필과 심사를 다른 회사 것으로 나누는 교차 심사 설계이기 때문입니다.

## 서버 실행하기

터미널에서 다음을 실행합니다.

```powershell
cd app
py -3.12 -m uvicorn novelcopilot.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

⚠️ 주의 — 이렇게 수동으로 실행하면 터미널 세션이 끝날 때 서버도 함께 종료될 수 있습니다.

## 상시 실행하기

컴퓨터에 로그인할 때마다 서버가 자동으로 시작되게 하려면 아래 스크립트를 관리자 권한으로 한 번 실행합니다.

```powershell
scripts/server_task_setup.ps1
```

한 번 등록하면 이후 로그인 시 자동으로 시작되므로 매번 터미널을 열지 않아도 됩니다.

## 코드 업데이트 반영하기

작품 데이터가 바뀐 것은 브라우저 새로고침만으로 바로 반영됩니다. 그러나 프로그램 코드를 업데이트했다면 서버를 다시 시작해야 반영됩니다.

⚠️ 주의 — 회차 생성이 진행 중일 때 서버를 재시작하면 진행 중인 작업이 끊길 수 있습니다. 생성이 끝난 뒤 재시작하세요.

## 데이터 위치와 백업

이 도구는 작가의 컴퓨터에서 도는 로컬 도구입니다. 작품·회차·설정·퇴고 이력은 모두 컴퓨터 안의 `app/data/projects` 폴더에 JSON 파일로 저장됩니다. 별도 서버로 전송되지 않습니다.

백업하는 두 가지 방법:

- **폴더 복사** — `app/data/projects` 폴더를 통째로 복사해 두면 전체 상태가 보존됩니다.
- **내보내기** — 작품 단위로 파일로 저장합니다. 방법은 [내보내기와 백업](export-backup.md)에서 다룹니다.
