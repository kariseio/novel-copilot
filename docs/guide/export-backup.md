# 내보내기와 백업

작품을 파일로 내보내고, 몰입형 읽기 모드로 확인하고, 데이터를 백업하는 법입니다.

## 작품 내보내기

작업실 오른쪽 위 **📤 내보내기**에서 작품을 zip 파일로 저장합니다. 압축을 풀면 회차마다 문서가 하나씩 나오며, 파일 이름이 `001화 · 제목` 식으로 매겨져 이름순 정렬이 곧 연재 순서입니다. 작품 소개가 있으면 `000 작품 소개` 문서가 함께 담깁니다.

- **텍스트 (.txt)** — 순수 본문
- **마크다운 (.md)** — 제목·구분선 등 서식 포함

## 읽기 모드

**📖 읽기 모드**를 누르면 편집 요소가 사라진 몰입형 읽기 화면이 열립니다. 웹소설 앱처럼 이전/다음 회차로 넘기고(`←` `→` 키 지원, `Esc`로 닫기), 글자 크기(`A−` `A+`)를 조절하고, 위쪽 선택 메뉴로 회차를 바로 이동할 수 있습니다. 읽던 회차는 기억됩니다.

## 데이터 백업

이 도구는 작가의 컴퓨터에서 도는 로컬 도구입니다. 작품·회차·설정·퇴고 이력은 모두 컴퓨터 안의 `app/data/projects` 폴더에 저장되며, 별도 서버로 전송되지 않습니다.

백업하는 두 가지 방법:

- **폴더 복사** — `app/data/projects` 폴더를 복사해 두면 전체 상태가 보존됩니다.
- **내보내기** — 위의 내보내기로 작품 단위 파일을 남깁니다.

자세한 데이터 위치와 상시 실행 설정은 [설치와 실행](setup.md)에서 다룹니다.
