# ARCHITECTURE — AI 웹소설 코파일럿 (v0.9.0)

> v0.9.0 실물 코드 기반 서비스 아키텍처 문서. 열망이 아니라 현재 구현을 기술한다.
> 짝 문서: 전체 프로세스 명세는 `docs/PIPELINE.md`. 컷 요약·기본값 동결표는 `docs/CHANGELOG.md`.

---

## 1. 시스템 한눈에

FastAPI 백엔드 + 바닐라 JS 프론트엔드로 구성된 단일 프로세스 서비스다. 작가가 시드/브리프를 던지면 **세계 생성**이 세계·인물·이야기 구조·설정집을 만들고, 이후 **회차 생성 하네스**가 회차를 한 편씩 집필한다. 핵심 설계 철학은 "harness over model" — 전진·검증·종료·라우팅은 결정론 코드가 쥐고, LLM은 계획/초안/재작성 같은 격리된 창작 지점에만 호출된다.

![레이어 스택: web(정적) → api(FastAPI) → services(파사드·세션/락) → engine(결정론 하네스·검증·게이트·패스) → worldgen / llm(집필·심사 AI 라우팅) → repository(로컬 JSON). 옆에 tools(실험·계측)는 의존성 격리(지연 import)](/img/docs/architecture-layers.svg)
*web → api → services → engine → (worldgen / llm) → repository. tools(실험·계측)는 엔진과 의존성 격리(지연 import). 아래 다이어그램은 텍스트 열람용.*

```
web(정적 HTML/JS/CSS, no-cache 재검증)
        │  fetch / 실시간 진행 스트림
        ▼
api(FastAPI 라우트)
        │
        ▼
services(코파일럿 파사드)
   · 유스케이스 오케스트레이션 · 세션/락 규율
        │
        ▼
engine(결정론 하네스 · 검증 · 게이트 · 편집 패스)
   · 회차 생성 루프 · 확정 설정 정합 검사
   · 검증 리포트 / 게이트 / AI 티 다듬기 / 재실현 / 문체 수리
        │                    │
        ▼                    ▼
worldgen                  llm(provider 추상화)
   · 세계 생성                · 역할별 provider 해소
   · 이야기 구조 설계         · "provider:model" 라우팅
   · 설정집 생성              · 이미지 클라이언트
        │
        ▼
repository(파일시스템 JSON)
   · 작품 상태 집계 루트 · 검색 샤드 · 표지 png

[격리] tools/ (실험·계측 — 형태소 분석 등). 엔진은 tools 를 로드타임에 import 하지 않는다.
       엔진 안 모든 tools 접근은 함수 내부 지연 import + try/except(부재 시 결측 정직).
```

조립 지점은 애플리케이션 생성 함수 하나다(Composition Root) — 설정 → 저장소/스킬 레지스트리 → 코파일럿 서비스 → FastAPI(라우터 + 정적 마운트). 정적 프론트엔드는 항상 재검증 미들웨어로 디스크 변경을 즉시 반영한다.

## 2. 설계 헌법 (코드에 실제 구현된 원칙)

이 원칙들은 슬로건이 아니라 코드에서 반복 확인되는 불변식이다.

1. **무강제(측정 → 가시화 → 작가).** 판정기·자동 재작성·자동 차단은 없다. 게이트/패스는 전부 opt-in + 원문 보호. 예: 발행 게이트·AI 티 다듬기·문체 수리는 config 토글이고, 실패여도 회차 발행 상태는 유지된다(기록·재시도만). AI 티 계측·드리프트·가상 독자 반응은 전부 참고선(판정기가 아니라 상대 추세 참고).

2. **하네스 결정론 · LLM 콜 격리.** 상태 전이(커서 전진·회차 추가·롤백)와 검증은 코드가 한다. LLM은 초안/이어쓰기/재작성, 요약, 확정 설정 추출, 게이트 심사 등 명시된 지점에서만 호출된다. 단계별 토큰은 스테이지별로 계측된다.

3. **집필≠심사 (교차 심사).** 심사 모델은 본문 모델과 다른 벤더로 라우팅된다. 본문 벤더가 한쪽이면 심사는 다른 쪽으로 자동 해소된다. 정독 게이트·재실현 정독 게이트·가상 독자 반응이 이 규칙을 따른다.

4. **pink-elephant / 앵커링 금지(긍정형 프롬프트).** 부정명령("~하지 마라")은 금지 대상 토큰을 오히려 프라이밍하므로 전부 긍정 구조지시로 전환돼 있다. 자기 이력·few-shot 예시를 컨텍스트에 노출하는 설계는 앵커로 역작동하므로, 회피 대상은 프롬프트가 아니라 **후보 풀 결정론 제외**로 차단한다(반복 필터·마무리 장치 순환).

5. **엔진 의존성 0 (tools 지연 로드).** 엔진 어느 모듈도 로드타임에 실험·계측 부품을 import 하지 않는다. 전부 함수 내부 지연 import + try/except → 부품 부재 시 조용히 결측(빈 결과), 생성은 계속.

6. **additive 하위호환.** 신규 필드는 전부 기본값 추가로 들어와 구 JSON이 바이트 동일하게 로드된다. 토글 OFF 시 프롬프트 바이트 동일이 계약이다.

7. **결측 정직("미실행" 명시).** 축이 안 돌았으면 null/빈 값이 아니라 문자열 "미실행"으로 명시한다 — 누락의 조용한 통과 차단. 검증 리포트의 형태소·도입부 반복도·가상 독자 반응·엔딩 계약·게이트 축이 모두 이 규약을 따른다.

## 3. 모델 라우팅 (config 실물)

역할별 provider는 교차 심사 라우팅으로 해소되고, 빈 값이면 본문 모델로, 키 부재 시 안전 폴백된다.

| 역할 | 값 | 근거 |
|---|---|---|
| 본문(프로즈)·핫패스 | `claude-opus-4-6` | 동급 품질·동단가이면서 토크나이저 인플레 없음(사용자 결정) |
| 세계 생성·설정집 | `claude-opus-4-8` | 세계관 설계 = 최신 모델(사용자 결정) |
| 이야기 구조 설계 | `claude-opus-4-8` | 심사 벤더 계열 장르 mode-collapse 회피 → 집필 벤더 필수 |
| AI 티 다듬기 윤문 | `claude-opus-4-8` | 윤문 품질 |
| 게이트·정독 심사 | 파생 — 본문이 집필 벤더면 심사=심사 벤더 | 집필≠심사 교차 심사 |
| 임베딩(검색·작품 노트) | `text-embedding-3-small` | 단일 임베딩 모델 정합(임베딩은 심사 벤더로 위임) |
| 표지 이미지 | `gpt-image-2` | 세로 표지 |

기본값 동결의 정본은 `docs/CHANGELOG.md` v0.9.0 "기본값 동결표"(서술자 목소리/AI 티 다듬기/문단 조판 정리/전개 압력 안내/재실현 정독 게이트 ON · few-shot/러닝 카운터/장면형 스타일 앵커/발행 게이트 OFF).

## 4. 데이터 모델 · 저장

**집계 루트 = 작품 상태.** 저장소가 직렬화하는 단일 aggregate. 주요 필드: 시드·세계·회차 목록·작가 지시·이야기 구조 커서·약속 원장·엔딩 계약·설정집·주입 스킬·동적 확정 설정 변경분(출처 추적)·검색/작품 노트 메모리 영속·표지 메타·누적 비용·재생성 이벤트 로그.

**회차 = 회차 레코드.** 본문·파생·검증·이력을 한 레코드에 담는다:
- 본문·요약: 최신본 1개·한 줄 요약·상세 시놉시스(~1,500자)·요약 폴백 신뢰강등 플래그.
- 서사 메타: 아크/에피소드·회차 기능·훅 유형·마무리 장치·시간 델타·장소.
- 참고선 신호: AI 티(분포+형태소)·드리프트 신호·사실 모순·가상 독자 반응·엔딩 계약 평가.
- 편집 이력: 문체 수리·AI 티 다듬기(전/후)·퇴고(추가 전용, 되돌리기 스냅샷 동봉)·퇴고 후 stale 배지.
- 검증 단일 출처: 검증 리포트(전축 집계 — 결측="미실행").
- 감사·디버그: 생성 입력 슬롯·라운드·설정 변경·스테이지별 사용량·초기/최종 충돌·회복 안내.

**온디스크 레이아웃**(작품 폴더):
- 작품 메인 JSON — 핫패스. 검색 임베딩은 제외(메타만). 원자적 쓰기(임시파일→fsync→교체).
- 검색 임베딩 회차별 샤드 — 지문으로 변경 시에만 재작성(write 증폭 방지).
- 표지 바이너리 png(메타는 메인 JSON).
- 재생성 되돌리기 blob — 마지막 회차 재생성 백업.
- 스킬 라이브러리 — 앱-전역(작품 간 공유, 별도 락).
- 선호 쌍 — 재실현 채택 시 축적(채택 성공 후에만 flush, 거절 승자 오학습 차단).

**세션 캐시·락 규율.** 세션 매니저는 LRU 캐시(락 잡힌 세션은 축출 제외). 미스 시 디스크에서 재수화(동적 상태 + 검색/작품 노트 import — LLM 재계산 회피). 세션 락은 **회차 생성 전체를 직렬화**하되, LLM 콜은 락 밖에서 도는 것이 규율이다: 퇴고/재실현/게이트 경로는 "짧은 진입 2회 패턴"으로 (1) 스냅샷·상태검사 (2) 최종 기록만 락 안에서 하고, 그 사이 LLM 콜은 락 획득 실패 시 즉시 락 응답 반환으로 lost-update를 막으며 락 밖에서 수행한다.

엔진 번들은 순수 데이터 조립(LLM 0콜)이고, 각 부품은 온디맨드로만 LLM을 호출한다.

## 5. 관측성

**진행 스트림.** 하네스의 모든 단계는 이벤트로 방출된다("조용한 정지 불가" 불변식). 토픽 예: 세계 생성·회차 계획·초안·확정 설정 검사·부분 재작성·메모리 조립·계획 검증·약속 원장·가상 독자·페이싱·드리프트·AI 티 다듬기·문체 수리·발행 게이트·검증 리포트.

**실시간 진행 스트림 엔드포인트.** 3개 스트림이 진행을 실시간 전달한다 — 작품 생성 파이프라인, 마지막 회차 재생성, 회차 생성. 회차 생성은 요청 수명과 생성 수명을 분리한다: 백그라운드 데몬 스레드가 끝까지 진행하고 이벤트를 버퍼링해, 연결이 끊겨도 새로고침/재접속 시 진행 중 작업에 다시 붙는다(멱등 시작 → 중복 회차 방지, 완료 작업은 6시간 보존).

**디버그 캡처.** 매 회차가 "어떤 정보로 설계·집필했는가"를 영속한다. 집필 system 헤더·작품 내 시각·엔딩 훅·최근 꼬리·확정 사실·앵커·지금까지 줄거리(길이 병기)·작가 지시·인물 명단·직전 회차 발췌·이어쓰기 콜 수·교정 단계 목록·회차 계획 슬롯이 담기고, 계획 키에는 아크/에피소드·등장인물 맥락·복선 노트·표현 절제·사건 메뉴·장르 계약이 담긴다 → 웹 생성 디버그 화면·매화 전축 보고의 원자료.

**비용 계측.** provider 인스턴스별 사용량(호출 수·토큰·임베딩)이 프로젝트별 비용으로 누적된다. 회차 단위는 스테이지별 사용량으로, 참고선 스테이지(사건 메뉴·원장 정산·가상 독자)도 별도 계상한다.
