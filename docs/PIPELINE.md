# PIPELINE — 전체 프로세스 명세 (v0.9.0)

> 작품 생성 → 회차 생성 → 편집 패스 → 검증까지 **전체 프로세스의 단일 출처**.
> v0.9.0 실물 코드 기반. 레이어 구조·데이터 모델·모델 라우팅은 `docs/ARCHITECTURE.md`.
> 단계별 표기 규약: **모델**=사용 provider 역할, **콜**=LLM 호출 수, **실패**=폴백 동작, **이벤트**=진행 스트림 방출.

## 1. 작품 생성 파이프라인

작가는 두 경로로 진입한다: (a) 대화형 컨셉 스튜디오 — 대화 턴이 브리프를 누적하고 시드로 변환, (b) 직접 시드 입력. 이후 작품 생성 파이프라인이 아래 단계를 실시간 진행 스트림으로 실행한다.

| # | 단계 | 모델 | 콜 | 실패 시 동작 | 이벤트 |
|---|---|---|---|---|---|
| 1 | **집착 벡터** — 세계를 균등 슬롯이 아니라 하나의 집착에서 편중 파생할 재료 | worldgen | 1 | 토글 OFF(기본)면 스킵 | 집착 |
| 2 | **세계 생성** — 시드→스키마 검증 세계(제목·인물·세계 규칙·문체). 브리프 명명 인물 바인딩(이름 발명 방지) | worldgen | 1~2(스키마 오류 시 보정 1) | 검증 실패 = 재시도 1 | 세계 생성 |
| 3 | **weird 비틀기** — 진부한 디폴트를 집착에 맞게 비튼다(엔티티 가감 없는 외과 재작성) | worldgen | 1 | 토글 OFF(기본)면 스킵, 예외 시 원본 유지 | weird |
| 4 | **이야기 구조 설계** — 엔딩-주도 역산 아크/에피소드 설계(1~8 아크·첫 아크 3~4 에피소드 해소, 나머지 지연 생성). 출력 절단 감지 시 재시도 | planning | 1~2 | 빈 구조(아크 0) = 평면 모드 폴백 | 구조 설계 |
| 5 | **설정집 생성** — 장르 카테고리별 설정집 산문(카테고리별 실시간 노출) | worldgen | ~13(카테고리별) | 예외 = 빈 설정집 | 설정집 |
| 6 | **저장 + 세션 초기화** — 작품 상태 조립·초기 메모리 영속 | — | 0 | — | 저장 |
| 7 | **서술자 목소리 파생** — 1인칭일 때만 주인공 시트→서술자 인격 파생·영속(이미 있으면 존중) | worldgen | 1 | 토글 OFF/비-1인칭/증거 부재 = 스킵 | 서술자 목소리 |
| 8 | **엔딩 계약 컴파일** — 이야기 구조의 엔딩을 술어 계약으로 컴파일(참고선 감시 재료) | planning | 1 | 예외/오류 = 스킵(생성 차단 금지) | 엔딩 계약 |

각 단계는 자기 격리(예외가 다음 단계·생성 전체를 막지 않음)이고 스킵도 이벤트로 가시화된다. 세계 생성 스킬(라이브러리에서 작가가 고른)은 조합 상한 적용 후 실제 반영분만 정직 기록한다.

## 2. 회차 생성 파이프라인 (핵심)

![회차 생성 8단계: 회차 계획 → 재료 조립 → 집필 → 사실 교정 → 문체 다듬기 → 파생물 → 검증 리포트 → 발행 게이트(옵션)](/img/docs/pipeline-chapter.svg)
*① 회차 계획 ② 재료 조립 ③ 집필 ④ 사실 교정 ⑤ 문체 다듬기 ⑥ 파생물 ⑦ 검증 리포트 ⑧ 발행 게이트 — 아래 2.1~2.10이 각 단계의 콜·실패 처리 상세.*

세션 락 안에서 권위 재읽기 → 파생 → 저장까지 한 트랜잭션으로 돈다. 확정 실패 시(빈/부분 생성·하드 비수렴) 커서·이야기 구조·회차 목록을 함께 롤백한다(반쪽 커밋 금지). 완결 조건(엔딩 도달 또는 하드캡=목표×2) 도달 시 완결 반환.

### 2.1 회차 계획 파생 (설계 단계)

이야기 구조 모드와 평면 모드(폴백)로 갈린다.

- **에피소드 조준** — 커서로 현재 에피소드 확정(빈 아크면 지연 생성 콜 1). 해소 중 완결 도달 시 완결 반환.
- **적시 사건 메뉴** — 에피소드 첫 회차에서 8~12 신선 사건 풀 1회 생성(콜 1/에피소드). 토글에 따라 중반 재생성 가능. 재료 조립: 등장인물 맥락·복선 노트·시간 팩트·최근 실현 회차 반복 후보 제거. 실패=결정론 폴백(예외 없음).
- **소비 원장 차감** — 이 에피소드에서 이미 지면에 실현된 필수/절정 사건을 결정론으로 차감해 반복 소스 차단. 피날레는 안전망 복원을 위해 전체 유지.
- **회차 계획 확정** — 회차 기능·훅 유형·마무리 장치·핵심 사건·시간 델타 라벨 포함. 재계획 시 최근 훅 유형·마무리 장치 화이트리스트를 대칭 전달.
- **계획 검증 하네스**(회차 계획도 본문처럼 생성→검사→교정): 확정 설정 정합·사건 이중발주·반복도(임계 초과)·무정산 연속 검사. 위반 시 명시 재계획 1회(무한 루프 금지), 잔존 시 보수 폴백(짧은 회차 수용·가시화). 밀도 플래그(over/thin/ok 참고선).
- **평면 모드**: 최근 4화 요약만 보고 다음 회차 계획(엔딩 전역 앵커 없음, 하위호환).

### 2.2 컨텍스트 조립

타입 분리 슬롯으로 조립된다. 콜 0(결정론 조립) — 검색만 임베딩 콜.

- **확정 사실(박기)** — 관련 인물의 확정 사실·관계 + 시계 파생 산술(계약 만기 잔여·현재 나이, 모델 산수 0). 프롬프트 최상단, 누락 0.
- **세계 규칙** — 확정 설정 슬롯으로 주입(낮은 신뢰 서술 아님).
- **작품 내 시각** — 구조화 델타 누적 절대시점(코드가 계산, 모델은 읽기만).
- **서사(찾기)** — 아크/엔딩 앵커 + 과거 회차 의미 검색(직전 회차 제외) + 인물 노트 검색 + 신규 데뷔 인물 소개 앵커. 옵션 ON 시 회차 계획 지목 인물 부재하면 타깃 검색 보강.
- **직전 회차 꼬리** — 직전 회차 원문(기본 8000자) 연속성.
- **서술자 목소리** — 인물 말투 시그니처 + 서술자 프레임(1인칭 주인공 목소리를 지문 서술 지시로 앞세움) + 표현 절제 + 고유명 표기-고정 앵커.
- **지금까지 줄거리** — 이야기 구조 모드는 계층 요약(최근 상세 + 먼 에피소드 롤업, 경계 기아 해소), 평면은 단순 요약. 예산 12000자. 절단·미달은 이벤트로 가시화.

### 2.3 초안 (본문 집필)

- **초안** — 회차 계획 하나를 자연스러운 절단점까지. 분량·장면 수는 모델 입력에서 제거(지시로 누르면 급결말·물타기). 온도 0.85, 출력 예산 6500토큰. 1화는 발단 전용 변형(in-medias-res→일상 grounding+전환). 절단 감지 시 잘린 꼬리만 제거·본문 보존.
- **이어쓰기 루프** — 출고 규범 미달이면서 회차 계획 미소진일 때만 전진(최대 4회). 재료 소진 시 짧은 회차 수용(분량≠밀도). 이어쓰기엔 직전 회차 전문·누적 줄거리를 빼고 "지금 쓴 본문 말미"만(재서술 압력 차단).
- **빈 응답 재생성** — 절단은 재생성 아님(잘라내기), 빈 응답만 제한적 재생성.
- **조판 복구** — 토막 행갈이 붕괴 시 내용 불변 재조판(공백 완전 검증 가드).

### 2.4 확정 설정 검사 → 교정

교정 루프(최대 3라운드): 확정 설정 검사(하드 충돌 검출) → 본문으로 고칠 수 있는 준-충돌만 재작성(콜 1/라운드) → 변경 한도 게이트(초과 시 원본 유지·본문파괴 차단). 확정 설정 자체의 자기모순은 본문으로 못 고치므로 가시화만. 최선본(하드 최소) 보존.

### 2.5 품질 게이트 (결정론 검출 → 국소 교정)

순서대로: 지시어 누출 제거 → 습관구 과용 패치(콜 1) → 말미 훅 반복 검출 시 국소 재작성(콜 1) → 연속성 다듬기(수치·인명·절단·메타·시제 패치, 콜 1) → 현재형 누출 교정(콜 1) → 메타 정리·구조 마크업 제거 → 문단 조판 정리(내용 무손실). 모든 교정은 패치 방식(LLM은 찾기/바꾸기 쌍만·코드가 정확일치 치환) — 본문 증발·절단 구조적 불가.

### 2.6 AI 티 다듬기 (마무리 직전·조판 후)

토글 ON(기본) 시: **결정론 티 탐지**(모티프 우려먹기[회차 간 원장]·문말 템플릿·발화 층위 벽·클리셰 수식, 콜 0) → **집필 AI 국소 수술**(스팬별 카테고리 처방·상한 6스팬, 콜 = 선별 스팬 수) → **변경률 가드**(5~30%·30%↑ 재검토) + 사실 표면 비교(확정 설정 불변). 실패/폴백=원문 유지+기록. 문체 리듬 수리를 흡수 — 이 패스 ON이면 리듬 수리를 따로 태우지 않음(이중 패스 금지). OFF일 때만 리듬 스팬 수리로 폴백.

### 2.7 요약·파생 (확정 회차만)

- **2계층 요약**(콜 1) — 한 줄 + 상세 시놉시스(~1,500자). LLM 실패 시 회차 계획에서 합성 폴백(프로즈 서두 슬라이스 금지·재상연 소스 차단·신뢰 강등).
- **의미 검색 색인·작품 노트 축적**(작품 노트 콜 1) — 멱등. 작품 노트 실패는 회차 확정을 막지 않음.
- **동적 확정 설정 갱신**(제안 콜 1) — 신규 인물·상태 변경·관계·설정 초안 추출(최종 검사 결과 소비·증거 강제). 미승인 설정집 초안 축적(작가 확정 게이트 보존).
- **약속 원장 정산**(콜 1) — 본문이 실제로 한 약속으로 원장 채움(설계 라벨 미러 아님).
- **가상 독자 반응**(콜 1) — 블라인드 장르 독자 행동 예측(참고선).
- **사실 모순 대조**(콜 0~1) — 자유형 사실 모순 검색 대조(비차단).
- **페이싱·드리프트·회고**(에피소드 피날레 시 롤업 요약·드리프트 신호).

### 2.8 문체 계측 · 회차 검증 리포트

- **AI 티 계측**(콜 0) — 정규식 자질(쉼표·문장 길이 변동·어휘 다양성·종결형 다양성·직유) + 형태소 문말 분포(과거형 지배율·연속 run·층위, 부품 부재 시 확장 생략). 판정 라벨 0·참고선. 생성·퇴고·되돌리기 모든 본문 변경 경로에서 동일 재계산(stale 차단).
- **회차 검증 리포트**(콜 0) — 확정 직후 전 축 결정론 집계 단일 출처. 축: 확정 설정·AI 티(+형태소+사람 글 범위)·도입부 반복도·분량·라벨·문체 수리·AI 티 다듬기·가상 독자 반응·엔딩 계약·사실 모순·게이트. 안 돈 축은 "미실행" 명시. 검토 필요 상태도 대칭 계산.

### 2.9 발행 게이트 (옵션·락 해제 후)

토글 OFF(기본) ON이면 확정·저장·**락 해제 후** 발행 게이트를 실행한다(게이트 내부 퇴고/재생성이 같은 세션 락을 비차단으로 잡으므로). 측정·리듬·교차 심사 판정을 조립해 게이트 루프를 돈다:

- **정독 심사**(교차 심사, 콜 1/라운드) → 판정/이탈 신호/수정 노트/예상 잔존율/악플.
- **국소 경로(기본)**: 이탈 신호가 본문에 앵커되면(정확 substring, 공백 정규화 1단계) 그 구간만 퇴고→채택 국소 퇴고(변동 차단). 앵커 실패/무변경/가드 불통과 = 전체 경로 폴백(재생성 1회).
- **최선 판본 보존**: 잔존 악화 시 되돌린 뒤 재시도 중단·최선 판본 전진(최악 잔존 차단).
- 콜 상한 12·재시도 2. 판정·라운드는 회차 검증 리포트로 영속. **무강제**: 실패여도 회차 발행 유지(기록·재시도만). 게이트 후 검증 리포트 재집계(게이트 포함).

### 2.10 상태 반환 · 사용량 스테이지

확정(하드 0 & 비어있지 않음) 또는 검토 필요. 검토 필요는 커서/이야기 구조 롤백 + 연속 2회 시 정체 경보(회복 안내 동봉). 반환 페이로드=회차·이벤트·사용량·실패 기록. 사용량 스테이지명: 초안·검사·재작성·품질·다듬기·AI 티 다듬기(또는 리듬 수리)·작품 노트·요약·사실 모순·사건 메뉴·설정 제안·원장 정산·가상 독자.

## 3. 편집 패스들 (작가 발동형 — 자동 임계 트리거 0)

### 3.1 퇴고

작가 지시로 산문만 다듬는다 — **사실 불변**. 설정·사건·수치·관계를 하나도 바꾸지 않고(확정 설정 프롬프트 주입 사전 바인딩) 표현·문체·조판만 개선한다. 선택 교정은 문단 조판 정리·시제 교정만(연속성/훅 재작성/습관구는 절대 금지). 구간 지정 시 그 구간만 다듬어 원위치 교체. 가드레일: **신규 하드 충돌 0** AND **사실 표면값 불변**(인물·키 교집합 값 변경 차단) AND 길이 가드(0.5~1.8). 채택은 새 버전 저장 + 서버 가드레일 재검증, 되돌리기는 마지막 비-되돌림 회차를 스냅샷으로 결정론 복원.

### 3.2 재실현

기존 확정 회차를 **원문 프로즈 없이(비앵커)** 사실 뼈대에서 웹소설 레지스터로 다시 실현한다(분포 레버는 비앵커 재실현 단독).

1. **입력 조립(결정론)** — 사실 뼈대=상세 시놉시스(부재 시 요약·둘 다 없으면 거부) + 대사 목록·수치 토큰·고유명사 + 서술자 목소리(1인칭). 프롬프트=분량 절대 자수 지시.
2. **후보 병렬 생성** — 같은 프롬프트 N회(기본 3·온도 0.85).
3. **결정론 리랭크 + 하드 실격**(콜 0) — 대사 유실·수치 누락·분량 실격 후, 형태소 사람 글 범위 최근접(top_ratio 밴드 → 최대 run → 과거형 비율) 리랭크. 형태소 부품 부재 시 첫 유효 후보로 강등(결측 정직).
4. **가드 스택** — 승자에 확정 설정 검사 + 사실 표면 비교(불통과 = 채택 금지·원문 유지).
5. **채택 정독 게이트**(기본 ON) — 후보 승자가 사람 글 범위에 들어도 교차 심사 양순서 2콜 정독에서 원문에 완패하면 채택 금지(원문 보호 원칙 — "범위≠품질" 재현 차단).
6. **채택 = 퇴고 제안** — 기존 퇴고 채택/되돌리기 계약 재사용(원문 항상 보존·되돌리기 가능·재요약 1콜은 생성 경로 동형). 선호 쌍은 채택 성공 후에만 축적(오학습 오염 차단).

### 3.3 표지

표지 프롬프트 합성(콜 1, 세로 2:3 영문 프롬프트·주인공 프로필 증거 게이트) → 이미지 생성(세로 표지). 바이너리는 표지 png, 메타는 표지 메타(재생성 시 history push). 중복 생성 락.

## 4. 검증 체계 요약

두 계층으로 나뉜다:

- **형태소 계측 축(참고선 — 조향 지표).** 문말 분포(top_ratio·최대 run·과거형 비율)·층위·파편율·도입부 반복도·정규식 자질. 사람 글 범위 병기("사람 글 범위 n~m" 라벨). **성공 판정 금지** — 1차 척도는 쌍대 정독 판별율. 엔진은 값+미실행만 산출(임계·라벨·색상 경고는 프레젠터 몫).
- **게이트 러너(실험용).** 실험/출고 러너가 생성→계측→수리→교차 심사 정독→국소 퇴고/재생성 루프를 돈다. 제품 경로와 **같은 엔진 부품**을 공유해 이중 구현을 없앴다. 중단 기준: 연속 실패-소진 3화 중단.
- **판정 언어 규칙.** 정독(쌍대 keep_reading 판별)이 1차 척도, 지표는 각주. 검증 리포트는 전 축 원자료를 담되 판정 라벨을 붙이지 않는다.

**검증 함수 배치**: 확정 설정=3등급 검사(하드/준-충돌/자기모순) → 회차 단일 출처=검증 리포트 → (옵션) 정독=게이트. 확정 설정 자기모순은 별도 결정론 검사(LLM 0).

## 5. 실측 계보 각주 (왜 이렇게 생겼는가)

이 파이프라인 형태의 근거가 된 핵심 실측 결론:

- **앵커 지배 이론**: 과거형 문말 지배의 지배항은 **컨텍스트 내 프로즈 앵커**(모델 attractor + 직전 회차 꼬리 자기 앵커). 문체 지시·기계 규칙·수치 상태블록은 앵커를 못 이긴다 → 문체 지시 실험 무효. 분포 레버는 비앵커 재실현 단독.
- **블랭킷 역효과**: "종결어미를 변주하라"는 블랭킷 지시가 역설적으로 변주를 낮춤 → 장면형 스타일 앵커 기본 OFF.
- **few-shot 오염**: 자기 생성물·예시 few-shot이 앵커로 역작동(악화) → few-shot 기본 OFF.
- **분량≠밀도**: 분량 하한 강제는 재설명·물타기를 낳음 → 이어쓰기 트리거를 "분량 하한"에서 "회차 계획 미소진"으로.
- **반복 소스차단**: 회피 대상을 프롬프트에 노출하면 프라이밍(pink-elephant) → 후보 풀 결정론 제외(반복 필터·소비 원장·마무리 장치 순환).
- **게이트 포화(변동)**: 스팬 지목 수정 노트에 전체 재생성만 응답하면 새 결함 태어남 → 국소 퇴고 라우팅·최선 판본 보존.
- **모델이 프로즈 레버**: 문체는 프롬프트보다 모델이 지배 → 본문 모델 확정.
